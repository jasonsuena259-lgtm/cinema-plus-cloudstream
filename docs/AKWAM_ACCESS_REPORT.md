# متابعة بلاغ غياب البطاقات وتفاصيل صقر وكناريا

التاريخ: 2026-10-28. أكد المستخدم أن الصفحة الرئيسية تفتح في متصفحه، لكن صفحة الفيلم لا تفتح. الصورة من CloudStream تظهر `The provider returned nothing for this page`.

أعدنا تشغيل كود الإضافة الفعلي في اختبار JVM. طلب الصفحة الرئيسية عبر `app` أعاد **HTTP 403** و9 بايت (`Forbidden`)؛ انتهى الاختبار الحي عند عدم وجود بطاقات. طلب المشاهدة في الاختبار الحي أعاد كذلك HTTP 403. هذه نتيجة **BLOCKED** وليست نجاح تشغيل.

في الفترة نفسها نجحت طلبات Python العادية في جلب الصفحة الرئيسية وصفحة فيلم صقر وكناريا 2026 وفيلم Star One وحلقة Tulsa King وقسم الأفلام. هذا يثبت اختلاف الوصول بين الطلبات، ولا يثبت سببه الدقيق أو صلاحية تشغيل الفيديو. لم نبدل الهوية أو نحاول حل CAPTCHA أو تجاوز رفض الموقع.

الكود الحالي لـ`AkwamProvider.page()` يُرجع null عند الرفض؛ `getMainPage()` يحوله إلى قائمة فارغة و`load()` يرجع null، فتظهر الرسالة العامة. تغيير الرسالة لا يعالج رفض الخادم.

حُفظت fixtures محلية من HTML الذي وصل بنجاح، مع إزالة scripts وبيانات data-* من تفاصيل الفيلم. تحتوي الصفحة الرئيسية على 62 بطاقة، منها بطاقتا `/post/` خارج نطاق الأفلام والمسلسلات، وتكرار واحد؛ ينتج 59 عنصرًا مدعومًا. اختبار `AkwamDetailsTest` يتحقق من بطاقاتها وصورها وتفاصيل الفيلم عبر Provider الفعلي وعميل HTTP محلي. نجاحه لا يعني نجاح الاتصال الحي.

لم نغيّر ملف الإضافة المنشور أو نرفع رقم الإصدار في هذه المتابعة؛ الإصدار الحالي يبقى أكوام v2. لا يوجد دليل يسمح بتقديم إصدار جديد على أنه إصلاح تشغيل. يلزم نجاح الوصول العادي لصفحات المحتوى والمشاهدة من التطبيق قبل إعلان حل البلاغ.

# OHA Live | أوها — CloudStream

إضافة مستقلة لقنوات OHA.TV المباشرة عبر واجهة OHA الجديدة المكتشفة في أكتوبر 2026.

## النطاق
- أقسام حسب 15 مجموعة دولية، بما فيها Arabia.
- بحث في أسماء القنوات، مع حدّ للصفحات لتقليل الحمل.
- معلومات القناة وصورتها إن أرجعتها واجهة API.
- استخراج روابط البث من `/live/resolve` وقت التشغيل بدل تخزين روابط موقعة تنتهي صلاحيتها.
- دعم HLS وDASH وروابط الفيديو المباشرة عند رجوعها.

## القيود
- الإصدار **تجريبي** حتى ينجح البناء في GitHub Actions وتجربة التشغيل على جهاز Android.
- لا يجلب أفلام ومسلسلات VOD؛ يحتاج بروتوكولًا منفصلًا عن `/live/`.
- تعتمد القوائم على استجابة السيرفر وتوفر دوله، وقد تكون بعض المجموعات فارغة.
- لا تتوفر فحوص اتصال مباشرة من بيئة التأليف؛ اختبار الكتالوج والـresolver على الشبكة الحية لم ينجز بعد.

## البناء
```bash
./gradlew OhaLive:make
```

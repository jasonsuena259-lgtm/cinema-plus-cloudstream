# FaselHD — تقرير الوصول والاختبار

تاريخ الفحص: 2026-10-28 (UTC). الموقع المطلوب: https://faselhd.info/.

## حالة التنفيذ

المهمة الجديدة مستقلة عن Cinema Plus وAkwam وTukTuk. لم تُعدّل الإضافات السابقة.
لا توجد نسخة FaselHD منشورة أو رابط تثبيت مثبت النجاح حتى الآن.

## الوصول للموقع

المستخدم أكد أن الموقع والتشغيل يعملان على اتصاله. البيئة هنا تلقت HTTP 403 وصفحة
`Attention Required! | Cloudflare` وبداخلها `Sorry, you have been blocked`.
هذا حظر للوصول من بيئة الفحص، ولا يثبت تعطل الموقع عند المستخدم.

| العنوان | HTTP | النتيجة |
|---|---:|---|
| `https://faselhd.info/` | 403 | BLOCKED |
| `https://www.faselhd.info/` | 403 | BLOCKED |
| `https://faselhd.info/movies` | 403 | BLOCKED |
| `https://faselhd.info/series` | 403 | BLOCKED |

آخر مسارين طلبات تشخيصية مستوحاة من المشروع المرجعي؛ لم يتم التحقق من أنهما أقسام هذا النطاق.
لم يُحاول تجاوز CAPTCHA أو Cloudflare، ولم تُستخرج بيانات محتوى من صفحة الحظر.

### نتيجة متصفح Chromium

لاحقًا أعاد تنقل عادي في Chromium 154 الصفحة الرئيسية الحقيقية برمز 200 مرة واحدة.
اكتُشفت 78 بطاقة `a.show-card`، منها 62 رابطًا فريدًا بعد حذف تكرار شريط العرض.
المسارات المثبتة للبطاقات: `/film/` و`/episode/`. البحث المعلن في الصفحة هو `/search?s=...`.
حُفظت بطاقات الصفحة الفعلية دون السكربتات أو بيانات الجلسة في `fixtures/fasel-home-cards.html`.
لكن فحوصات المتصفح التالية للرئيسية والفيلم والحلقة والمشغل أعادت 403، وكذلك إعادة محاولة واحدة.
إذًا الوصول متقطع، ولم يثبت حل الحظر أو الوصول المستقر. راجع `FASELHD_BROWSER_RESULTS.json`.
تفاصيل الطلبات القابلة للمراجعة: `FASELHD_HTTP_RESULTS.json`.

## مراجعة المرجع

تمت قراءة [FaselHD.kt](https://github.com/mehdigm4life/mehdigm-stream/blob/9817ae1f6b3b5a7871c1619b3737a29c77ff9022/FaselHD/src/main/kotlin/com/faselhd/FaselHD.kt).
المرجع يستخدم `https://www.fasel-hd.co/` وليس النطاق المطلوب.
به محددات `.postDiv` و`.blockMovie` و`#seasonList .seasonDiv` و`#epAll a`،
ومسار مشغل داخلي، لكن لم يتم إثبات مطابقة هذه البنية للموقع المطلوب.
لا ننسخ منطق تجاهل أخطاء TLS أو تجاوز الحماية منه. لم يُنسخ كوده إلى إنتاج المشروع.

## دليل المستخدم المصوّر

أرسل المستخدم لقطة لصفحة الحلقة تظهر أسماء الأزرار التالية كما كُتبت:
`savefiles`, `uqload`, `byse`, `vinovo`, `voe`, `doodstream`, `streamtape`,
`m1xdrop`, `pixeldrain`, `earnvids`, `ok`.
هذه أسماء ظاهرة في واجهة الموقع، وليست قائمة روابط مستخرجة أو سيرفرات ثبت تشغيلها من هنا.
لا تكشف الصورة خصائص HTML أو طلبات الشبكة أو الجودات. أرسل لاحقًا صورًا أخرى فيها إطار فيديو وإحصاءات المشغل: HLS، و1432×720، ومخزن مؤقت 32.92 ثانية.
هذا دليل من جهاز المستخدم على تشغيل مصدره المحدد؛ ليس اختبارًا مستقلًا من بيئتنا أو دليلًا على بقية السيرفرات.
اسم الملف الظاهر ينتهي بـ MP4، لكن نوع النقل في الإحصاءات HLS؛ لا يصح استنتاج تنزيل MP4 مباشر منه.

## شروط استئناف التنفيذ

يلزم الوصول المسموح والمستقر لصفحات فيلم ومسلسل وموسم/حلقة وصفحة المشغل. الرئيسية فقط توفرت مرة واحدة.
أرسل المستخدم رابط مشاهدة «Lupin الموسم الرابع الحلقة 1» على المسار `/watch/`.
فُحص الرابط نفسه دون تغيير، وأعاد 403 وصفحة الحظر أيضًا؛ التفاصيل في `FASELHD_EPISODE_HTTP.json`.
لا يمكن استنتاج أسماء السيرفرات أو جوداتها أو إتمام إضافة موثوقة من صفحة حظر.

## اختبارات المحتوى

| الاختبار | الحالة | السبب |
|---|---|---|
| استخراج بطاقات الرئيسية من اللقطة الحقيقية | PASS | 62 رابطًا فريدًا؛ لا يثبت الوصول المستقر أو تشغيلها |
| المواسم والتفاصيل | BLOCKED | صفحة حماية بدل HTML المحتوى |
| اكتشاف السيرفرات والتحقق من المقاطع | BLOCKED | لم تصل صفحات محتوى حقيقية |
| مشاهدة/تقديم وتأخير داخل CloudStream | NOT_TESTED | لا توجد مصادر مكتشفة موثقة |
| تنزيل عينة من رابط Savefiles الذي أرسله المستخدم | PASS | مقطعان، تحويل حاوية حقيقي إلى MP4 وفك ترميز ناجح؛ ليس تنزيل CloudStream |
| تنزيل داخل CloudStream | NOT_TESTED | التطبيق لم يثبت بنجاح في المحاكي |
| بناء إضافة FaselHD ونشرها | NOT_TESTED | لم يُنشأ مزود مبني على بيانات غير مثبتة |

## رابط Savefiles المقدم من المستخدم

الرابط عبارة عن قائمة HLS موقعة مؤقتًا، وليس ملف MP4 مباشرًا. لم يوضع الرابط أو توقيعه
في المستودع. أعادت القائمة HTTP 200، وكانت قائمة وسائط فيها 325 مقطعًا، دون master
أو تعريف جودات متعددة أو مفاتيح تشفير في القائمة المختبرة.

نُزّل أول مقطعين بحالة 200 ونوع `video/MP2T`، ثم فُحصا بـ ffprobe:
فيديو H.264 بدقة 1280×532، وصوت AAC، ومدة العينة 20.033333 ثانية.
جرى تحويل الحاوية بـ ffmpeg إلى MP4، وليس تغيير الامتداد، ثم فك ترميز 3 ثوانٍ بنجاح.
حجم MP4 الناتج 3,325,995 بايت. البصمة والنتائج في `FASELHD_MEDIA_SAMPLE.json`.
هذا لا يثبت تنزيل العمل كاملًا أو التقديم والتأخير أو التحميل داخل CloudStream،
ولا يثبت ربط هذا المصدر بعمل معين؛ الرابط أرسله المستخدم ولم تستخرجه إضافة.

رابط مشاهدة VisionQuest الذي أرسله المستخدم اختُبر كذلك في Chromium وأعاد 403.

## اختبار Android الفعلي

جُهز Android Emulator 37.2.12 وصورة Android 11 x86_64 وجرى تشغيلهما عبر ADB.
لم يتوفر KVM. المحاولة الأولى انتهت بمهلة إقلاع وإعادة تشغيل خدمات النظام،
وسجل `DeadSystemException`. في المحاولة الثانية ظهر `sys.boot_completed=1`،
لكن محاولة تثبيت CloudStream 4.8.0 الرسمي فشلت برسالة:

```text
adb: failed to install ...: cmd: Failure calling service package: Broken pipe (32)
```

سجل النظام أظهر إعادة تشغيل zygote وخدمات النظام وقت الفشل. هذا عائق في المحاكي،
وليس نتيجة اختبار إضافة FaselHD. لم يتم فتح CloudStream أو تشغيل إضافة بداخله بنجاح.
تفاصيل البيئة في `ANDROID_TEST_SETUP.md`.

## ما يلزم الآن

حفظ صفحة مشاهدة تعمل من متصفح المستخدم كملف HTML/MHTML قد يتيح تحليل الأزرار
وطلبات المشغل. قد لا يتضمن الملف طلبات الفيديو اللاحقة. لا تكفي صور الأزرار أو
رابط HLS المؤقت لبناء استخراج تلقائي لكل الأعمال. لا يوجد رابط تثبيت جديد جاهز.

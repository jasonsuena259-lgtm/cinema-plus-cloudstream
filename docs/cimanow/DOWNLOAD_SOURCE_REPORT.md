لم نعتبر 200 على صفحة HTML تشغيلًا ناجحًا. Forafile اختُبر بطلب النموذج الطبيعي، ثم توقيع ftyp، وتنزيل 3 ثوانٍ، وقراءة ffprobe وفك ثانيتين بـffmpeg، ثم مستخرج Kotlin نفسه. لا تنزيل للحلقة كاملة ولا اختبار seek داخل التطبيق.

الدخول داخل الموقع مطلوب لاكتشاف روابط بقية الأعمال. نسخة CimaNowVIP v1 تضيف نافذة تسجيل دخول محلية وتنفذ وظائف Provider أساسية، لكنها **نسخة اختبار غير مثبتة على حساب VIP أو Android**. المقصود اختبار الوصول بعد الدخول، وليس الادعاء بانتهاء الإضافة. لا جلسات أو بيانات حساب في المستودع.

# اختبار TukTuk Cinema v1

التاريخ: 2026-10-28. **اختبارات JVM والشبكة لا تعادل التشغيل على جهاز Android.**

## التحقق

- اختبار `getMainPage`: 40 بطاقة فعلية.
- اختبار `load` لفيلم All of a Sudden 2026: تفاصيل وصورة صحيحتان.
- اختبار `load` للحلقة محمد الفاتح S04E07: 90 حلقة في المواسم 1–4، مع روابط منفصلة.
- اختبار `search("Mehmed")`: 20 نتيجة فعلية.
- اختبار resolver الإنتاج يجلب بيانات المشغل حديثًا ويحل المصادر ويقرأ manifest/variant وجزءًا أوليًا. MP4 يُفحص بطلب Range وcontent-type/توقيع الحاوية؛ لا يتم تنزيل ملف كامل.
- fixtures محلية تختبر الصور، فك ترميز روابط الموقع العادي، اختلاف مصادر الفيلم والحلقة، المواسم والأرقام، JSON التالف، HTML المتغير، والحفاظ على الجودة 1072 دون افتراض 1080.

## ملخص المستضيفين

| المستضيف | تحقق Kotlin من رابط الفيديو | حدود الفحص |
|---|---|---|
| earnvids | PASS للفيلم والحلقة | HLS؛ النجاح لا يضمن دوام الرابط |
| streamruby | PASS للفيلم والحلقة | نجحت العينة النهائية وffprobe بعد توحيد ترويسة User-Agent؛ حدث فشل لمحاولة سابقة |
| Firestream | PASS للفيلم والحلقة | HLS في العينة النهائية؛ نجح ffprobe. تذبذبت بعض المحاولات السابقة |
| vidara | PASS للفيلم والحلقة | HLS؛ لم يُختبر كل المحتوى |
| doodstream | BLOCKED | صفحة تحقق؛ لم تُتجاوز |
| mixdrop | BLOCKED | reCAPTCHA في الصفحة؛ تُستبعد تحفّظيًا |
| upnshare | UNSUPPORTED في الاختبار | المستخرج المتاح لم يُخرج رابطًا صالحًا |
| byse | UNSUPPORTED في الاختبار | المستخرج المتاح لم يُخرج رابطًا صالحًا |

عينات الفيلم الصوتية والمرئية المفحوصة عبر ffprobe محفوظة في [TUKTUK_MEDIA_PROBE.jsonl](TUKTUK_MEDIA_PROBE.jsonl). `partial_download` يعني تنزيل عينة قصيرة فقط، ولا يعني تنزيل الفيلم أو اختباره في CloudStream. قد تتغير النتائج بتغير توقيع المصدر أو رفض الاستضافة.

التشغيل داخل التطبيق، التقديم والتأخير، والتنزيل الكامل: **NOT_TESTED**؛ لا يوجد جهاز Android متصل. لا يُعلن اكتمال شروط تشغيل كل محتوى الموقع.

## إعادة الاختبار

```sh
./gradlew TukTukCinema:testDebugUnitTest TukTukCinema:make
TUKTUK_LIVE_TEST=1 ./gradlew TukTukCinema:testDebugUnitTest --rerun-tasks
```

الفحص الحي اختياري ولا يعمل افتراضيًا في CI. لتصدير روابط مؤقتة للفحص على جهاز المطوّر، اضبط TUKTUK_PROBE_EXPORT إلى مسار خارج المستودع، ثم شغّل `python3 tests/probe_tuktuk_media.py /path/to/export.json`. لا تنشر ذلك الملف لأنه يحوي روابط مؤقتة؛ مخرجات الفاحص لا تطبعها.

البناء النهائي: `BUILD SUCCESSFUL`. اجتازت الاختبارات السبعة (4 محلية و3 حية) دون فشل أو استثناء. اجتازت العبارات الـ29 في المشروع فحص ICU. تحقّق التغليف من نقطة الدخول ومن عدم وجود مزوّدي Cinema Plus أو أكوام داخل ملف TukTuk. لم يتغير ملفا الإضافتين السابقتين.

الفحص النهائي المستقل: اجتازت عينات HLS من المستضيفين الأربعة تنزيل الجزء وقراءة بيانات h264/aac عبر ffprobe (1616×1072). مسار فحص MP4 مهيأ إذا أعاد المضيف رابطًا مباشرًا، لكن عينة MP4 مستقلة لم تُثبت في هذه الجولة.

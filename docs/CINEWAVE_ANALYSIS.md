# CineWave: تحليل الموقع

تم الفحص في 2026-10-28 و2026-10-29 على https://cinewave.org.lk/.
الموقع Next.js؛ HTML الأولي لا يحتوي بطاقات المحتوى، لذلك لا تستخدم الإضافة محلل بطاقات HTML.

## المصادر المثبتة في JavaScript الموقع

- `/api/movies/all?page=N`: `movies`, `page`, `totalPages`.
- `/api/tv/all?page=N`: `tvShows`, `page`, `totalPages`.
- `/api/movies/search?q=...` و`/api/tv/search?q=...`: `results`.
- `/api/movies/get?id=550`: تفاصيل الفيلم في `movies[0]`.
- `/api/tv/get?id=1399`: تفاصيل المسلسل و`seasons[].season_number/episode_count`.
- صفحة `/watch/movies/550` وتحميلاتها تحتوي مصفوفة `buildMovieUrl/buildTvUrl`.
- صفحة `/watch/tv/1399` تستخدم أرقام المواسم وعدد الحلقات لبناء قائمة الاختيار،
  ولا توفر في البيانات التي فُحصت أسماء وصورًا خاصة بكل حلقة. تتبع الإضافة ذلك دون اختلاق أسماء.

الكود المرصود: `_next/static/chunks/0adbday8qojop.js` للقوائم والبحث،
`0jw~8lp0semg8.js` لمشغل الأفلام، `0nl-jxqwvy34g.js` لمشغل المسلسلات.
هذه أسماء بناء متغيرة؛ الإضافة تكتشف أسماء ملفات JavaScript من صفحة المشغل وقت الطلب.
نماذج JSON ومصفوفة السيرفرات الفعلية محفوظة في `CineWave/src/test/resources/`.

## السيرفرات

MoviesAPI, VidLink, VidSrc, XPass, VidEasy, 111Movies, 2Embed, Mapple, PrimeSrc,
HNEmbed, VidUp, VidFast, VidRock. أسماء مستخرجة من الموقع وليست أسماء مخترعة.
تُقرأ قوالب URL حرفيًا دون تنفيذ JavaScript الموقع في JVM.
قوالب TV الخاصة بـ MoviesAPI وVidLink وHNEmbed لا تحتوي الموسم والحلقة،
فتُستبعد لتجنب تشغيل حلقة مختلفة؛ باقي القوالب العشرة تربط كليهما.
أُصلح خلط معرفات Anime/AniList بمعرفات TMDB باختبار مسار القالب ونوعه.

## معنى وجود المحتوى

البيانات كتالوج يعتمد TMDB، ويضيف الموقع روابط مشغلات مبنية من المعرفات.
هذه ليست قاعدة مخزون تؤكد وجود كل فيديو؛ وجود بطاقة أو `playerUrl` لا يثبت توفر المشاهدة.
الإضافة تعرض كتالوج الموقع المرتبط بقوالب مشغلاته، ولا تدعي فحص توفر كل عنوان.
هذا قيد معروف: لا يوجد حاليًا ترشيح مسبق يثبت توفر فيديو لكل بطاقة قبل عرضها.

## حل الروابط

تُجرّب مستخرجات CloudStream أولًا، ثم WebView عادي للمشغل عند عدم وجود نتيجة.
يُلتقط طلب HLS الفعلي مع Referer وUser-Agent وCookies الخاصة به. لا تُحفظ روابط
المقاطع أو تواقيعها في الإنتاج؛ لا يتم تجاوز CAPTCHA أو تجاهل TLS.
التزامن محدود بثلاثة مشغلات، ولكل مصدر مهلة مستقلة. مصدر فاشل لا يلغي بقية المصادر.
التحقق يفحص manifest، أول variant، مورد التهيئة إن وجد، مفتاح HLS AES-128 العادي
إذا كان متاحًا بصورة عادية، وبنية MPEG-TS أو ISO BMFF داخل أول مقطع.
SAMPLE-AES وKEYFORMAT/DRM مرفوضة. لا يُعتبر HTTP 200 بمفرده نجاحًا.

قائمة HLS الرئيسية تحتفظ بالمسارات الصوتية المضمنة، والجودات تستخرج من manifest.
ترجمات المستخرجات الموجودة تُمرر؛ لا يوجد استخراج كامل للترجمات من WebView بعد.
MP4 وDASH غير مدعومين في محقق الإصدار الأول. يدعم الإصدار مسار HLS الذي ثبت وجوده.

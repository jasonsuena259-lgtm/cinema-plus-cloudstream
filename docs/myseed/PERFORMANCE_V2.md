# MySeed v2 — تقليل انتظار السيرفرات

الإصدار السابق انتظر awaitAll لكل المضيفين، ثم أرسل الروابط وفحص الجودات بالتتابع. الإصدار 2 يرسل الرابط المتحقق منه داخل مهمة المضيف فور جاهزيته. توسعة الجودات تأتي بعد رابط HLS الرئيسي ولا تؤخر مصادر أخرى.

- ستة مضيفين متوازيين؛ متصفحان فقط في الوقت نفسه.
- مهلة إجمالية 25 ثانية لمرحلة السيرفرات، و18 ثانية لكل مضيف بما فيه بديل المتصفح والجودات. المهلة الإجمالية لا تشمل طلب صفحة play.php السابق لها.
- HTTP الاستخراج بمهلة 8 ثوانٍ؛ طلبات التحقق 6 ثوانٍ وقابلة للإلغاء الفعلي عبر OkHttp.cancel. تبقى إعادة التحقق المحدودة والتحقق من بيانات الوسائط.
- انتهاء المهلة يحتفظ بالنتائج التي وصلت، لكنه قد يستبعد مصدرًا شديد البطء. رابط HLS الرئيسي يحافظ على الجودات الداخلية حتى إذا انتهت مهلة تعدادها.
- لا تُحفظ روابط تشغيل مؤقتة ولا يُستبدل التحقق بفحص HTTP 200 فقط.

اختبارات SourceDispatcher الأربعة تثبت الإرسال المبكر، الاحتفاظ بالنتائج عند انتهاء المهلة، عزل فشل المضيف، واحترام إلغاء المستدعي. نجح البناء واختبارات التحليل المحلية، ثم اختبارات الفيلم والحلقة وفشل مصدر منفرد مباشرة. لا اختبار أداء داخل Android في هذه الجولة.

التحديث متاح عبر مستودع v1 الموجود بالفعل؛ plugins-myseed-v1.json يشير إلى ملف الإصدار 2. لا يلزم إضافة مستودع جديد.

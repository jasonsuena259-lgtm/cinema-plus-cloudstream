## البناء واختبارات التحليل

`CinemaPlus:make CinemaPlus:testDebugUnitTest makePluginsJson --rerun-tasks` نجح باستخدام JDK 21 وAndroid SDK 35 وGradle 8.12 وKotlin 2.4.0؛ أربعة اختبارات JUnit نجحت. أزيلت تحذيرات D8 الأصلية بتحديث R8 إلى 9.5.28؛ لا يزال Gradle يحذر من أن 8.12 سيصبح قديماً مع إصدار Kotlin مستقبلي. فُحص أرشيف cs3 باستخدام `unzip -t` واحتوى manifest وclasses.dex. SHA-256: `30f328a4090ef3e12d80d4ecfe945b72593904364cde3565c7741278669f0e21`. هذا لا يثبت قابليته للتشغيل في التطبيق. اختبار JSON المعطوب وانقطاع الاتصال وتكامل CloudStream ليس ضمن الاختبارات الأربعة.

# أكوام v2 — إصلاح استخراج الروابط

التاريخ: 2026-10-28. السيناريو المبلغ عنه: محمد الفاتح سلطان الفتوحات، الموسم الرابع، الحلقة 6؛ تظهر الأزرار في الموقع لكن الإضافة لا تُرجع روابط.

## النتائج والتغييرات

- رابط المشاهدة العربي من HTML كان يُمرر إلى `Referer` دون ترميز URL. يرفض OkHttp الأحرف العربية الخام في الترويسات بـ `IllegalArgumentException`. أضيف اختبار يعيد إنتاج الرفض ثم يتحقق من قبول الرابط المرمّز. تُحفظ الحروف العربية في عنوان الصفحة مع ترميزها الصحيح في طلب HTTP.
- أصبح التشغيل يطلب مسار المشاهدة العام `/watch/{slug}` مباشرة، وهو المسار المرصود في الموقع للأفلام والحلقات، دون طلب صفحة التفاصيل مرة أخرى. لا يُستخدم هذا للوصول إلى صفحة تطلب تسجيل الدخول أو تحديًا.
- استُبدل اعتماد Lulu/Fastvid/Fastved على `JwPlayerHelper` بمحلل محدود للمصادر المرصودة (`sources` و`hls2/hls3/hls4`، بما فيها master.txt). يحافظ على Referer الخاص بالمستضيف، ويتحقق من HLS قبل إخراج الرابط. تُستخدم `JsUnpacker` للكود المعبّأ المعتاد دون فك DRM.
- تُعزل `LinkageError` الخاصة بمستخرج غير متوافق مع إصدار التطبيق، فلا تلغي حل بقية السيرفرات. تستمر الاستعانة بمستخرجات CloudStream الأخرى دون ادعاء دعمها جميعًا.
- تُعرض رسائل تشير إلى HTTP أو التحقق المطلوب أو عدم توافق المستخرج عندما لا ينجح أي مصدر.

## نطاق الاختبارات

الاختبارات المحلية لا تحتاج الإنترنت. تشمل ترميز Referer العربي، استخراج المصادر المباشرة والمتغيرات، إزالة التكرارات، وبنية الفهرس والحلقات. `AkwamResolverTest` يمر عبر resolver الفعلي وNiceHttp/OkHttp مع interceptor محلي: صفحة مشاهدة وجلسة وPOST وحل المستضيف وmaster وvariant وجزء اصطناعي؛ ويتأكد من عدم تعطيل السيرفر المعطل للرابط الناجح. بياناته fixtures وليست روابط إنتاج أو دليل فك فيديو فعلي.

الاختبار الحي المنفصل: `AKWAM_LIVE_TEST=1 ./gradlew Akwam:testDebugUnitTest --rerun-tasks`. يفحص الحلقة المذكورة بكود الإنتاج، ولا يطبع الروابط الموقعة. لا يُشغّل افتراضيًا داخل CI.

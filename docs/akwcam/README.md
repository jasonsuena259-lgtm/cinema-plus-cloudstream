# AkwCam | أكوام

إضافة مستقلة لموقع https://akw.cam/ تشمل الأفلام والمسلسلات والحلقات والتصنيفات والبحث والصفحات التالية، مع توسيع مرايا Share4max. الإصدار تجريبي: ليس كل مستضيف يعمل، واختبار Android داخل التطبيق غير مثبت.

أضف رابط المستودع في إعدادات CloudStream ← الإضافات ← إضافة مستودع:

```
https://raw.githubusercontent.com/jasonsuena259-lgtm/cinema-plus-cloudstream/main/repo-akwcam-v1.json
```

ثم ثبّت **AkwCam | أكوام**. لا يلزم حذف Cinema Plus أو CimaNow أو Akwam القديمة؛ الإضافة مستقلة عنها.

عند فتح بطاقة حلقة يُعرض مسلسلها بكامل المواسم والحلقات التي ينشرها الموقع. روابط التحميل القابلة للاستخراج والتحقق تظهر مع روابط المشاهدة في مشغّل/مدير تحميل CloudStream؛ صفحات التحميل التي تتطلب CAPTCHA أو اشتراكًا لا تتحول إلى فيديو وهمي. لا يوجد ضمان أن كل رابط بالموقع قابل للتحميل داخل التطبيق.

البناء: `./gradlew AkwCam:testDebugUnitTest AkwCam:make`. الاختبار الحي اختياري عبر `AKWCAM_LIVE=1` مع مسار كتابة خاص خارج المستودع كما في الاختبار؛ الاختبارات الافتراضية تستخدم fixtures محلية. لا تُنشر ملفات الفحص الخاصة أو روابط CDN.

# تحليل MySeed

المصدر https://myseed.baby/main؛ الفحص المباشر بتاريخ 2026-10-29. القالب HTML من جهة الخادم، وليس API عامًّا لـTMDB. لا تُعرض أعمال من مصادر خارج فهرس الموقع.

## الأقسام والبحث

القائمة الفعلية تحتوي 16 قسمًا؛ عناوينها ومساراتها بالترتيب في MySeedParser.sections ومثبتة باختبار sectionsMatchRealMenu ضد home.html. يبدأ الترتيب بالأكثر مشاهدة والجديد، ثم مسلسلات وبرامج عرب سيد والتصنيفات العربية والتركية والأجنبية والكورية والبرامج والأنمي والهندية، ثم الأفلام وتصنيفاتها. الموقع نفسه يعرض «لا توجد اى ملفات بهذا التصنيف حالياً» لبعض الأقسام؛ تُقبل الحالة دون اختراع بطاقات.

البطاقات: `.thumbnail .caption h3 a[href]`، رابط `watch.php?vid=...`، الصورة من data-src ثم data-original ثم src. الربط بالمعرّف vid المستقر. البحث الأصلي `search.php?keywords=...&page=N`، يدعم النص العربي والإنجليزي. ترقيم الصفحات من `.pagination` باستخدام query parameter page، لا بتخمين وجود صفحة تالية.

## التفاصيل والحلقات

عنوان `h1[itemprop=name]`، صورة og:image، وصف `.pm-video-description [itemprop=description]`، تصنيفات من روابط category.php في dd. لا نضع تقييمًا أو سنة غير موجودة؛ السنة تؤخذ من العنوان حين تظهر.

`.SeasonsBox .tablinks` تربط هدف openCity باسم الموسم الظاهر. مثال Silo: معرّف التبويب Season1 لكنه **الموسم الثالث**؛ لا يجوز تحويل معرّف DOM إلى رقم الموسم. الحلقات تؤخذ فقط من `.SeasonsEpisodesMain .tabcontent`، رقمها من em، ورابط كل حلقة من watch.php?vid. بطاقات التوصيات خارج هذا الحاوي لا تصبح حلقات. ثبت وجود 11 حلقة في الصفحة المدخلة وفي صفحة المسلسل `vid=31f4adaa7`. اختبار فيلم `vid=d507467a3` نجح.

## التشغيل

من watch.php إلى play.php بنفس vid عند كل طلب. `.list_servers li[data-embed]` يحتوي HTML iframe؛ اسمه strong. العينة تعرض 16 مصدرًا، وأول iframe يكرر المصدر الأول فلا يضاف مرتين. روابط Vidspeed وMp4 وVidmoly تطابق معرّفات الأمثلة التي أرسلها المستخدم.

خط الاستخراج: اكتشاف iframe → حل صفحة المضيف → التحقق من الوسائط → ExtractorLink. Dean Edwards packed JavaScript يُفك بـJsUnpacker دون تنفيذ نص خارجي. النصوص المباشرة تدعم HLS وMP4 المثبتين. Vidara يوفّر API عام /api/stream؛ Upzur يضع مصدر MP4 في مصفوفة hex معكوسة؛ VOE يضع تحويلًا عامًا لنفس الفيديو؛ Streamhls يحتوي نموذج POST /dl، وقد فُحص دون إثبات رابط صالح. المصادر الأخرى تستخدم extractors التطبيق، ثم WebView عادي عند الحاجة؛ البديل غير مثبت داخل Android.

Referer وUser-Agent مأخوذان من سياق المشغل؛ لا تعطل TLS، ولا تتجاوز حظرًا أو CAPTCHA. كل مضيف معزول بمهلة، وحد التزامن أربعة. فشل مضيف لا يلغي روابط الآخرين. مصادر الفيديو لا تُخزن دائمًا.

التحقق من HLS يفحص EXTM3U، قائمة الوسائط، المفتاح الاعتيادي AES-128 عند توفره علنًا، ومقدمة جزء TS/fMP4؛ DRM/SAMPLE-AES غير مدعوم. جودة master تُقرأ بـM3u8Helper، ولا تُخترع جودة من اسم زر. MP4 يُفحص بتوقيع ftyp. ترجمة Vidara تُرسل إن أعاد API ملفات ترجمة؛ لا ادعاء توفر ترجمة لكل حلقة. المسارات الصوتية داخل HLS يترك اختيارها للمشغل. لا يوجد دليل يستدعي اختراع دعم DASH.

## الاختبارات

Fixtures محلية مأخوذة من HTML الحقيقي مع حذف scripts/forms، لا تتطلب شبكة. تشمل الأقسام، البطاقات، pagination، ربط المواسم، الحلقات، منع تسرب التوصيات، السيرفرات، تكرارها، الروابط الناقصة وتغير HTML. الاختبارات الحية مستقلة عبر MYSEED_LIVE_TEST=1. نتائج المشاهدة والتنزيل على الكمبيوتر موثقة منفصلة عن Android في SERVER_TEST_REPORT.md.

# CimaNow VIP v4 — نسخة تجريبية

المستودع الحالي يستقبل v4 دون إعادة تثبيت أو تغيير الحساب:

```text
https://raw.githubusercontent.com/jasonsuena259-lgtm/cinema-plus-cloudstream/main/repo-cimanowvip-v1.json
```

حدّث الإضافة وتأكد من ظهور v4، ثم أعد اختيار CimaNow VIP لتحديث قائمة الأقسام. يبقى تسجيل الدخول من ترس إعدادات الإضافة؛ لا ترسل كلمة المرور أو الكوكيز.

## تغييرات v2

- أقسام مستقلة: الرئيسية، الأحدث، الأفلام، المسلسلات، البرامج؛ روابطها من قائمة الموقع. ترقيم صفحات الأقسام عند وجود رابط صفحة تالية.
- استبعاد YouTube والتريلرات والإعلانات من السيرفرات.
- قراءة رابط مشاهدة الحلقة الصحيحة وانتظار مصادر المشغّل بدل الاكتفاء بظهور العنوان.
- عندما لا تظهر المصادر تلقائيًا، تفتح نافذة الموقع: افتح الحلقة، اختر سيرفرًا، اضغط تشغيل، ثم «متابعة التشغيل». تُفحص الروابط الملتقطة قبل إرسالها إلى مشغّل CloudStream. يمكنك اختيار أكثر من سيرفر قبل المتابعة.

أكد المستخدم دخول v1 وظهور الكتالوج. **نافذة تشغيل v2 والأقسام داخل Android لم تُختبر لدينا بجلسة حساب؛ لا ضمان بأن كل تبويبات الموقع تُستخرج تلقائيًا.** إذا لم يجد قسمًا في قائمة الموقع، تظهر رسالة توضحه بدل اختراع رابط. البحث GET من نموذج الموقع مدعوم؛ POST ما زال غير مدعوم.

الجلسة محلية في CookieManager. تسجيل الخروج من الموقع داخل نافذة الإعدادات؛ لا حساب مشترك أو token ثابت. التحقق اليدوي للموقع لا يُتجاوز. يُستخرج Forafile عبر نموذج التحميل الطبيعي وقد اجتاز اختبار الفيديو؛ بقية المستضيفين تعتمد على Extractors التطبيق أو طلبات المشغل المرصودة والتحقق منها.

## إصلاح الأقسام v3

أُزيل خطأ «لم يظهر رابط قسم البرامج». تُعرض الأقسام التي اكتُشف رابطها فقط، ويعود اختيار القسم القديم المفقود إلى الرئيسية. يدعم اكتشاف الأسماء الأيقونات وaria-label وصيغ «البرامج التلفزيونية». [التفاصيل والاختبارات](../docs/cimanow/V3_CATALOG_FIX.md).

## فتح رابط Chrome في v4

إذا حُجبت بوابة الانتقال داخل الإضافة لكن ظهرت السيرفرات في Chrome، انسخ رابط صفحة المشاهدة النهائية. من إعدادات الإضافة أو نافذة التشغيل اضغط «فتح رابط المشاهدة من Chrome» والصقه. عند ظهور السيرفرات اختر مصدرًا واضغط تشغيل، ثم «متابعة التشغيل». لا ترسل الرابط أو الكوكيز إلى المطوّر.

الرابط مؤقت داخل الذاكرة لمدة 10 دقائق وللحلقة نفسها فقط. لا نقل تلقائي لجلسة Chrome؛ قد يرفض الموقع الرابط في جلسة WebView أيضًا. [التفاصيل والاختبارات](../docs/cimanow/V4_WATCH_LINK_IMPORT.md).

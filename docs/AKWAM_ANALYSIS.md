# تحليل أكوام ومرجع الإضافات

الفحص 2026-10-27. مشروع المرجع `mehdigm4life/mehdigm-stream`، commit `30b3bc21e65eb1650af627c60d2166bf919d483d`: الهيكل متعدد الإضافات، كل إضافة تسجل `MainAPI` داخل Plugin، وتقدم أقسامًا وبحثًا وصفحات وتستخدم `loadExtractor` مع الترويسات المناسبة. مثال `CimaCloud.kt` يعزل جلب البيانات وينظم الحلقات، و`FaselHD.kt` يستعين بالمستخرجات. راجعنا التصميم دون نسخ آليات لتجاوز الحماية.

أكوام: الصفحة الرئيسية والقوائم `/category/...` والبحث `/search?s=...` تستخدم بطاقات `a.show-card` تحتوي عنوانًا وصورة. بطاقة الحلقة تفتح `/episode/...` وتحتوي روابط إلى `/series/...` والموسم؛ صفحة المسلسل تحتوي `a.epss` إلى مواسمها، وصفحة الموسم تحوي حلقات `a.epss` وأرقامًا في `.fs-2`. صفحات الفيلم والحلقة تربط إلى `/watch/...`. صفحة المشاهدة تعرض أزرار `data-token` و`watchResolveKey` وCSRF؛ نستخدم طلب الموقع العادي `/watch/resolve` مع كوكيز الجلسة، و`human_signal: null` كما تتيح شيفرة الموقع، ولا نتخطى أي تحدٍّ. الرابط الناتج يحوَّل بواسطة الموقع إلى المستضيف. لا تُحفظ رموز الجلسة أو عناوين الفيديو المؤقتة في المشروع.

الأزرار المرصودة لعينة Star One تشمل vinovo وuqload وvoe وdoodstream وluluvido وm1xdrop وbyse وearnvids وok. ظهور الزر لا يعني صلاحية المصدر. بعض المستضيفين يُظهر CAPTCHA أو يرفض الاتصال؛ نتخطى التحديات. للبقية تُستخدم مستخرجات CloudStream، مع دعم JWPlayer المعبأ عبر أداتي `JsUnpacker` و`JwPlayerHelper` الموجودتين في التطبيق للمستضيفين المرصودين luluvido.com وfastvid.cam وfastved.cam. فحص الروابط يشمل manifest وأول جزء لـHLS؛ لا يتم تجاوز DRM أو المصادقة أو CAPTCHA.

فيلم «في أعماق النهر» في الصورة هو Under Paris (TMDB 1001311). بطاقة Cinema Plus له `go:1001311` ولا تكشف مصدرًا، لكن أكوام يعرضه عند البحث عن Under Paris. جُرّبت عملية الموقع على fastved.cam ونجح جلب manifest وجزء أول، ولم يختبر تطبيق CloudStream أو التنزيل الكامل. Star One على luluvido اجتاز الفحص الشبكي نفسه. أعاد VK خطأ اتصال 403 في البيئة وlisteamed خطأ 401؛ لا تُعد تلك المصادر ناجحة. الحالات تتغير مع الوقت.

الاختبار القابل للتكرار: `python3 tests/probe_akwam.py` و`python3 tests/probe_akwam.py --under-paris` (يتطلب lxml والإنترنت). يتم إرسال طلبات عادية، ولا يطبع رموز الجلسة أو روابط موقعة. الاختبار ليس تشغيلًا داخل CloudStream.
